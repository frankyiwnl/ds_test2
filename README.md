# Bot Traffic Detection

Решение задачи классификации cookie по вероятности принадлежности к автоматизированному трафику.

Модель принимает историю событий пользователя и предсказывает вероятность того, что cookie относится к бот-трафику.

Целевая переменная:

- `target = 1` — автоматизированный трафик;
- `target = 0` — пользовательский трафик.

Основная метрика: Precision при Recall >= 70%.

---

## Data

Используемые данные:

```
data/
├── train.csv
├── test.csv
├── events.csv.gz
└── sample_submission.csv
```

### train.csv / test.csv

Метаданные cookie и окна наблюдения:

- `cookie_id` — идентификатор cookie;
- `cookie_created_at` — время создания cookie;
- `window_start_ts` — начало окна наблюдения;
- `window_end_ts` — конец окна наблюдения;

### events.csv.gz

История событий пользователей:

- `user_agent`
- `item_id`
- `item_category`
- `item_location`
- `seller_type`

- `pointer_y`

---

## Solution Overview

Решение состоит из следующих этапов:

1. Фильтрация событий по окну наблюдения каждого cookie.

2. Построение агрегированных признаков на уровне `cookie_id`.

3. Обучение модели классификации.

4. Валидация на временном разбиении.

5. Генерация файла с предсказаниями.

---

## Feature Engineering

Признаки строятся только на основе доступной истории событий.

### Activity Features

- количество событий;
- количество уникальных объявлений;
- количество уникальных категорий;
- количество уникальных продавцов;
- количество уникальных поисковых запросов;
- количество страниц поиска.

### Event Distribution Features

- доли типов событий;
- количество уникальных значений категориальных полей;
- распределение действий пользователя;
- энтропия категориальных признаков.

### Time Features

Из `event_ts`:

- час активности;
- день недели;
- длительность активности;
- количество событий в единицу времени;
- интенсивность действий.

### User-Agent Features

Используются:

- длина строки User-Agent;
- наличие технических признаков клиента;
- частотные характеристики.

### Ratio Features

Добавлены поведенческие коэффициенты:

- события / длительность окна;
- уникальные объекты / количество событий;
- уникальные категории / количество событий.

## Model

Основная модель:

```python
CatBoostClassifier
```

Параметры модели:

```text
iterations = 800
depth = 7
learning_rate = 0.04
loss_function = Logloss
l2_leaf_reg = 5
auto_class_weights = Balanced
```

---

## Validation

Используется временное разбиение данных.

Причина выбора:

Тестовая выборка соответствует более позднему периоду, поэтому случайное разбиение может приводить к завышенной оценке качества.

Используются метрики:

- ROC-AUC — диагностическая метрика;
- Precision при Recall >= 70% — основная метрика.
